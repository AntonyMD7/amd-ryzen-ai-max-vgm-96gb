# Science, Research & Environment — Public Reference Layer

**Roadmap status:** `P-183` through `P-194` are **IN PROGRESS** reference work only.

## Search-before-build

Use mature scholarly/reproducibility/data standards instead of building parallel infrastructure. Crossref exposes reusable scholarly metadata; Zotero is an established research-source manager. ReproZip captures computational experiment dependencies/executions; RO-Crate specifies machine- and human-readable research-object metadata; Frictionless Data Package/Frictionless tooling describes and validates datasets. These systems should be integrated where appropriate rather than duplicated.

## Boundaries

- P-183/P-185 record DOI/title/source metadata only; metadata presence is not paper quality, claim validity or full-text permission.
- P-184/P-186/P-188 bind artifact roles/hashes and upstream reproducibility candidates; hashes/environment manifests do not prove reproducibility without an independent rerun.
- P-187 records dataset source/license/hash but does not infer that rights are valid or sufficient.
- P-189 is an open-data query plan only; no portal request or dataset selection.
- P-190 describes a public API wrapper surface without credentials, generation or network calls.
- P-191/P-192 require timestamped source/field manifests; no weather/water safety decision can be inferred before fresh authoritative data and domain thresholds.
- P-193/P-194 perform transparent watt-hour arithmetic only; estimates are not power-meter measurements or efficiency certification, and tariffs remain unverified unless freshly sourced.
